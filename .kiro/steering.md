# Contexto do Projeto — AWS AI Practitioner AIF-C01

## Objetivo
Plano de estudos para aprovação na certificação AWS Certified AI Practitioner (AIF-C01).
Data da prova: 28/09/2026.

## Metodologia
- Estudo por blocos temáticos dentro de cada domínio (5 domínios)
- Conceitos em arquivos `.md` separados por bloco
- Questões em arquivos separados (`*-questoes.md`) com `<details>` para gabarito (funciona no GitHub)
- Tudo versionado em repo privado no GitHub
- Fluxo: conceitos → questões → correção explicada → próximo bloco
- Mini-simulado ao final de cada domínio
- Simulados completos (65 questões, 90 min) ao final

## Estrutura de Arquivos
```
00-visao-geral-prova.md
01-dominio1/
  01-tipos-de-machine-learning.md (conceitos)
  01-tipos-de-machine-learning-questoes.md (questões com <details>)
  ...
02-dominio2/
03-dominio3/
04-dominio4/
05-dominio5/
06-simulados-finais/
```

## Regras para Questões
- Estilo da prova: múltipla escolha (4 alternativas) e múltipla resposta (5-6 alternativas)
- Só elaborar questões após confirmar que a resposta está correta
- Questões devem estar alinhadas com o escopo do AIF-C01
- Gabarito explicado: por que a correta é correta + por que as erradas estão erradas
- Fontes: documentação AWS oficial, exam guide, sample questions

## Domínios e Pesos
1. Fundamentos de IA e ML — 20%
2. Fundamentos de IA Generativa — 24%
3. Aplicações de Foundation Models — 28%
4. Diretrizes para IA Responsável — 14%
5. Segurança, Conformidade e Governança — 14%
